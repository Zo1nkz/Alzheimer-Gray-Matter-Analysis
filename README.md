# Alzheimer-Gray-Matter-Analysis

Does gray matter volume in the frontal and left parietal lobes help distinguish
cognitively normal adults from those with cognitive impairment? This project
explores that question with a 2,700-participant subset of the National
Alzheimer's Coordinating Center (NACC) dataset, controlling for years of education.

Completed for MATH 220 (Statistics), Spring 2026.
